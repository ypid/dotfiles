`*-config` files serve as entry point. Other snippets that are not meant to be used directly/alone.

--key=value cli option syntax is preferred unless value is a path so that Vim
can easily open the path.

yt-dlp entry point/default config is ~/.config/yt-dlp.conf. Do not create config nor config.txt here to avoid confusion. This directory is fully symlinked from the dotfiles git repo.
